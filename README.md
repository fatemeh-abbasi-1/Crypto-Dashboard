# Crypto Dashboard

A responsive and user-friendly crypto dashboard built with React, focusing on clarity, usability, and clean UI.

## Problem
Most crypto dashboards are overloaded with information and difficult to use on mobile devices.  
Users need a clear and simple way to track key market data without confusion.

## Target Users
- Beginner crypto users
- Traders who mainly use mobile devices
- Users who want a quick market overview instead of complex analytics

## Features
- Cryptocurrency price overview
- Market change indicators
- Clean and minimal dashboard layout
- Fully responsive design for mobile, tablet, and desktop

## UX & UI Decisions
- Mobile-first design to ensure usability on small screens
- Important information displayed first
- Simple layout to avoid cognitive overload
- Clear typography and spacing for better readability

## Tech Stack
- React
- JavaScript (ES6+)
- CSS / Tailwind / Bootstrap
- API-based data fetching

## Goals
The main goal of this project is to practice building real-world dashboards with a strong focus on user experience, responsiveness, and component-based architecture.
